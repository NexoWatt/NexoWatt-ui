NexoWatt EOS 0.8.173 RC49 – direkter npm-Publish
==================================================

1. Den Inhalt dieser ZIP vollständig in den Projektordner kopieren.
2. Vorhandene Dateien ersetzen.
3. PowerShell im Projektordner öffnen.
4. Ausschließlich ausführen:

   npm publish

Der Publish-Vorgang prüft read-only:
- ob Version 0.8.173 auf npm noch frei ist,
- ob sämtliche freigegebenen Produktdateien exakt dem geprüften RC49-Artefakt entsprechen.

Nicht erforderlich:
- npm ci
- npm install
- npm update
- npx tsc
- Build- oder Sync-Befehle

NexoLogic-Testmodus:
- läuft ausschließlich im Browser,
- schreibt keine Hardwaredatenpunkte,
- verändert keine aktive Serverlogik.
