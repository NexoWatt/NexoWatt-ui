NexoWatt UI 1.0.6 – OFFICIAL STABLE RELEASE

Aus dem frisch entpackten Repository veröffentlichen:
npm publish --tag latest

Vor Veröffentlichung: npm run release:check
Versionsverfügbarkeit und Artefaktversiegelung werden vom vorhandenen prepublishOnly-Guard geprüft.
Bereits veröffentlichte Versionsnummern nicht erneut verwenden.

Basis: vollständiges Repository 1.0.4. Details: docs/STABLE_1_0_5_RELEASE_DE.md.
Änderung: Speicherschutz bleibt bei veralteter Wallbox-Telemetrie erhalten.
Bei unbekannter geschützter Fahrzeuglast wird die Speicherentladung vorübergehend
insgesamt gesperrt, da der NVP allein Haus und Fahrzeug nicht sicher trennen kann.
Laden aus echtem Gesamtüberschuss bleibt möglich. Frische Werte stellen den
bisherigen Normalbetrieb wieder her; eine gewählte Mitnutzung bleibt unverändert.

Nach Update Adapter neu starten und Browser neu laden. Kontrolliert prüfen:
Schützen/Mitnutzen, Telemetrieausfall und Wiederkehr, PV-/Speicherübergabe.
Keine Hardware-Dauertests oder automatische npm-Veröffentlichung durch diese ZIP.
